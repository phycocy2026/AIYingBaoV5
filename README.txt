AIYingBaoV5
版本：V5.0.0

本版新增“推荐对象”：
1. 普通人群
2. 儿童青少年
3. 老年人
4. 运动人群
5. 心血管健康关注人群

推荐逻辑综合：
性别 + 年龄 + 身高 + 体重 + 健康目标 + 活动水平 + 今日步数 + 推荐对象 + 食物识别结果

心血管健康关注人群：
- 强调少盐、少油
- 减少加工肉、腌制食品、油炸食品和重口味酱汁
- 增加蔬菜、鱼类、豆类和全谷物
- 仅用于健康教育和日常饮食参考，不替代医生或营养师的个体化诊疗意见

部署说明：
本次只修改前端推荐逻辑。
GitHub Pages 更新 index.html、app.js、styles.css、top5_translate.js 即可。
Render 后端无需更新。

V5.0.1：心血管健康关注人群新增糖尿病、高血压、高血脂、肥胖细分；选择后更新三餐文字。该选择不用于诊断，也不改变热量和蛋白质计算公式。
一般饮食建议参考：https://www.who.int/news-room/fact-sheets/detail/healthy-diet

V5.0.2：四种健康细分使用独立三餐方案，保留身体信息、目标、活动、步数及识别结果联动；细分选择不直接改变营养指标公式。

V5.0.3：蛋白目标加入活动水平联动。一般演示系数：久坐1.0、轻度1.2、中度1.4、高强度1.6 g/kg；减脂加0.2、增肌加0.4，估算系数最高2.0。步数不再叠加蛋白系数，避免重复计入活动。
上述四档及目标加值为本程序的简化估算规则，并非指南规定的分档。疾病、成长阶段和肾功能异常者的实际目标需个体化制定。
参考背景（运动人群蛋白范围）：https://ods.od.nih.gov/factsheets/ExerciseAndAthleticPerformance-HealthProfessional/

V5.0.4：推荐对象与蛋白目标联动。普通人群沿用活动系数，运动人群系数下限1.4，老年人下限1.2；再加目标增量，上限2.0。分档为程序演示估算，不是个体处方。
儿童青少年、未满18岁者及心血管健康关注各细分采用个人方案目标；未填写时显示待设定。糖尿病、高血压、高血脂、肥胖和一般健康关注分别记录当前页面中的目标，切换不会串用，刷新后清除。个人方案不随体重、活动或增肌目标自动加量。三餐建议同步显示目标。
依据：糖尿病蛋白需求需个体化，不能仅按疾病名称赋予系数。https://doi.org/10.2337/dc25-s005

V5.0.5：按用户要求调整普通成人一般估算，四档活动系数为0.8、0.9、1.0、1.2；久坐60kg为48g。男性65g、女性55g作为人群参考展示，不作个人目标固定值或最低值。活动分档是产品简化规则，不表示指南规定。
保留目标调整：减脂增加0.2、增肌增加0.4；运动对象下限1.2；老年对象或65岁及以上下限1.0，上限1.5；其他自动估算上限2.0。个人方案优先。此处仅记录实现规则，界面不展示公式。
移除左侧每日小目标及固定72%完成度。
参考：https://www.cma.org.cn/art/2023/7/14/art_4584_51668.html

V5.0.6：步数与蛋白目标联动。步数分档：不足5000步0.8，5000–7999步0.9，8000–11999步1.0，12000步以上1.2。与所选活动档位取较高值，不相加，再应用原有对象和健康目标规则。分档为产品简化估算，并非临床步数到蛋白质换算标准。
活动提示与蛋白估算使用同一活动判断，避免久坐但高步数时仍提示活动少。个人方案目标不受步数覆盖。界面保持不显示公式。

V5.0.7：新增独立推荐对象“肾功能不全”，包含尚未确认、未透析、透析中三种状态，各自保留当前页面中的个人蛋白目标。蛋白目标未填写时显示待设定；热量不套用成人自动增肌减脂公式，显示待设定，由个人方案安排。
三餐围绕蛋白个体化、减少钠和含磷添加剂、血钾血磷指导下选择食物、尿量及治疗方案指导液体安排。透析并非一律低蛋白，不统一限钾限磷限水。不自动推荐补蛋白或补水，不据照片推断矿物质或食物对肾病的安全性。分期、急慢性及合并疾病需治疗团队进一步评估。
